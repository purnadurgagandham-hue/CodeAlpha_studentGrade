# Student Grade Tracker

## Description
Student Grade Tracker is a Java console application that helps manage student grades. It allows users to enter student names and marks, calculates the average, highest, and lowest scores, and displays a summary report.

## Features
- Add student names and grades
- Calculate average marks
- Find highest score
- Find lowest score
- Display all student records
- Console-based interface

## Technologies Used
- Java
- OOP (Object-Oriented Programming)
- ArrayList
- Scanner

## Project Structure
```
CodeAlpha_studentGrade/

```

## How to Run
1. Clone the repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the program:
   ```
   javac Main.java
   ```
4. Run the program:
   ```
   java Main
   ```
